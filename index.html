Research

What we work on

FAIR Data & Semantic Publishing

Ongoing project

We are lead authors of the FAIR Principles, and build software that makes data and scientific assertions Findable, Accessible, Interoperable, and Reusable — and that can autonomously evaluate how FAIR a resource really is.

Semantic Web infrastructure

Core lab expertise

SADI Semantic Web Services, SPARQL-based federated query, ontology engineering, and tools that let researchers and machines discover and query distributed biological data sources.
